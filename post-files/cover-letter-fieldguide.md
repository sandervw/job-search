# Question Answers

## Question 1

When I pushed to roll out agentic coding tools org-wide I had to decide how much autonomy to grant an AI agent touching prod. I designed a security framework around least-privilege logins scoped per environment, plus managed settings and a custom MCP for our specific SQL server warehouse. That let engineers use Claude Code while keeping a read-only boundary between generated code and production data. I brought the other devs along by conducting early training sessions, for both the software and data engineering teams.

## Question 2

When our reporting vendor collapsed I became sole technical decision-maker for the rebuild, reporting directly to company leadership. I created structure by tracking the old platform's outputs, then building documented, tested internal services. What I got wrong early on was scoping too broad. I tried putting in enhancements around performance and simplification instead of focusing on like-for-like metrics first, which complicated testing and deployment.

## Question 3

I recruited and onboarded a senior engineer onto a team that had been running on undocumented, single-owner systems, and introduced him to the library of custom Claude Code skills the team uses for daily work. Several of our siloed systems for external state/federal reporting are now ones anyone on the team can pick up and extend.
